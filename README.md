# Google Advanced Data Analytics Portfolio

This repository contains projects completed as part of the Google Advanced Data Analytics Professional Certificate.

The portfolio demonstrates practical experience in:

- Exploratory Data Analysis (EDA)
- Data preprocessing
- Statistical analysis
- Predictive modeling
- Machine learning
- Model evaluation
- Data visualization

## Projects

### Waze Churn Prediction
Predicting user churn behavior using machine learning models and behavioral data.

### Google Capstone Project
End-to-end analytics workflow involving data preparation, exploratory analysis, model development, and interpretation.

### Course Activities and Mini Projects
Selected exercises and smaller projects completed throughout the program.
